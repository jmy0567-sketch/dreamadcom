# 갤러리아 광고주 후보 — 누구에게 소통할까 (11/12 분석)

## 결론
- 댓글·좋아요는 **"갤러리아 광고비를 낼 수 있고, 갤러리아 고객이 곧 자기 고객인 곳"**에만 한다.
- 가장 큰 후보(분양 현장·대형 병원)는 인스타 계정이 없거나 대행사가 광고를 돌린다 → **댓글이 아니라 전화·방문 영업**이 맞다. 매일 리스트 맨 위에 "오늘 전화 1~2곳"을 따로 둔다.
- 남의 글 댓글은 **인스타 계정이 확인된 A·B등급만**. 못 채우면 개수를 줄인다(엉뚱한 곳으로 채우지 않음).

## 등급 기준
| 등급 | 업종 | 이유 | 접근 |
|---|---|---|---|
| A | 아파트 분양 현장·분양대행사, 병원 개원(피부·성형·치과·안과·한방·정형), 수입차 전시장, 웨딩홀 | 객단가 크고 광고 예산 큼, 갤러리아 고객(30~60대·구매력)이 바로 고객 | **전화·방문 + 무료 시안** (SNS는 보조) |
| B | 입시·대형 학원 개원·설명회, 대형 가구·인테리어, 프랜차이즈 지역 신규 지점, 프리미엄 피트니스 | 학부모·입주·신혼 수요 = 백화점 고객과 겹침 | 인스타 소통 2~3회 → 시안 DM |
| C (제외) | 단독 식당·카페, 셀프사진관, 1인 샵(눈썹·네일·미용실 개인점), 온라인 쇼핑몰, 다른 지역 업체, 인력 모집 글 | 광고비 규모·고객층이 안 맞음 | 하지 않음 |

추가 신호(있으면 우선): Meta 광고를 동시에 여러 개 돌림 · 최근 2주 안에 시작 · 광고 문구에 "백화점·신세계·프리미엄" · 대행사가 여러 곳 붙음(= 마케팅 예산 큼).

## 11/12 실제 데이터에서 보인 것
- 천안은 **아파트 분양 광고가 압도적**: 휴먼빌 퍼스트시티(성성, 1,541세대)는 대행사 5곳 이상이 동시에 광고, 삼거리 벽산블루밍 4개 동시, 두정역 푸르지오 그랑피크는 광고에 "신세계백화점 생활인프라"를 씀, 천안아산역 그랑시티 필하우스(1,534세대)는 11/9 새로 시작. → 갤러리아 천안 센터시티 주차장 입구·EV홀 화면 18곳의 1순위 고객.
- 진주는 Meta 분양 광고가 거의 없음 → 진주는 병원·학원·수입차(디엠모빌리티 벤츠) 중심. 치과 임플란트 광고는 대행사 이름으로만 나와 병원명을 알 수 없어 제외.
- 11/12 아침 리스트 재점검: 럭피스튜디오(셀프사진관)·스튜디오 다믐(서울 출장 스냅)·샤브74(식당)·이가자헤어·뷰티인사이드·언니네필라테스 = **C등급, 빼야 했음**. 에듀플렉스 천안성성(B)·디엠모빌리티(A)·비렌티 웨딩홀(A)만 맞았음.

## 리스트 형식 (신불당 매뉴얼 9-1 방식 그대로)
인사(오늘 할 일 수) → 🎉 성과 → ① 우리 글 답글 → 📞 오늘 전화 1~2곳(A등급, 대표번호·한 줄 대본) → ② 인스타 댓글(계정 링크 → ❤️ → ①추천 ②짧게 코드블록) → ③ 스레드(업체 계정 확인된 곳만, 없으면 생략) → ❤️ 좋아요만(링크) → 📌 시안 DM 후보 → 끝인사.

## 한계 (솔직히)
- 클라우드에서는 인스타·스레드 화면이 열리지 않아 **글 하나하나의 주소**를 못 뽑음 → 계정 주소(instagram.com/아이디)를 드림. 누르면 계정이 열리고 **맨 위 최신 글**에 좋아요·댓글. 댓글 문구는 최신 글이 무엇이든 어울리게 업체 자체에 맞춰 씀.
- 글 주소까지 꼭 필요하면 PC 세션(크롬)에서 같은 리스트에 링크만 채우게 할 수 있음.
